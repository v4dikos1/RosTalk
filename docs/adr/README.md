# Архитектурные решения (ADR)

Каждое существенное решение проекта записано отдельным документом: контекст,
решение, последствия. ADR новее [технического решения](../TECHNICAL_DESIGN.md)
и при расхождении имеют приоритет. Отступаете от дизайна — добавьте новый ADR
со следующим номером.

ADR — журнал на момент решения. В них встречаются ссылки на материалы, которые
в публичный репозиторий не входят: прототипы этапа 0 (`spikes/`), внутренний
журнал приёмки (`docs/REVIEW.md`), план этапов и скриншоты приёмки
(`docs/assets/`). Выводы из них перенесены в сами ADR.

До версии 0.3.0 проект назывался Hearth (ADR 0033); в старых ADR имя уже
заменено.
