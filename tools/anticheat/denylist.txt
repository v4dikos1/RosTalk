# RosTalk anti-cheat denylist (stage 2.3.3).
#
# One POSIX extended regular expression per line (`grep -E`); a line starting
# with `#` is a comment. The rules come from the table "Запрещено всегда" in
# docs/anticheat.md, section "Античит-гигиена", and are matched
# against the client sources: client/src-tauri/**/*.rs|toml and
# client/ui/src/** (see tools/anticheat/check.sh for the exact scope).
#
# Convention: a line that is a bare lowercase identifier (letters, digits, `_`
# or `-` only, for example `rdev`) is used twice: as a source regex and as a
# crate name checked against `cargo tree` for the Windows target. Every other
# line is a source-only regex.
#
# Whole-line comments in the sources do not count as usage: a doc comment that
# explains why `SetWindowsHookEx` is forbidden is not a hook. check.sh skips
# lines that start with `//`, `/*` or `*/` (Rust/TypeScript) and `#` in TOML.
#
# Anything not covered here is not automatically allowed: the white list in the
# plan is the ceiling (CONTRIBUTING.md, "Anti-cheat safety").
